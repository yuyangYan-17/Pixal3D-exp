# Archived legacy experiments

These standalone scripts and launchers were used by earlier geometry/PBR/flow
experiments. They are kept outside the active root entry points and are not
imported by the current global-C4096/local-C1024 flow.

The active experiment is centered on:

- `pixal3d_global_c4096_visible_local_flow.py`
- `pixal3d_multiview_fixed_geometry_pbr_gaussian_sr.py`
- `pixal3d_tile_c1024_local_slat_and_local_decode_return_global.py`
- `pixal3d_cross_tile_pbr_perstep.py`
- `pixal3d_texture_visibility_guided_pbr_flow.py`

The archived output directories were removed separately; the retained output
tree contains the current CUDA4 run and the baseline assets required to render
and compare it.
