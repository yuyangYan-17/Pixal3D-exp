# **Trellis2 分辨率影响验证**

**目标 **

**验证 Trellis2 现有不同生成分辨率是否真的会带来质量提升，以及这个提升是否会被 mesh simplification 抹掉。**

---

**1\. 实验设置**

准备至少 **20 张 input images**。

每张图跑 Trellis2 自带的四种设置：

```Plain Text
512
1024
1024_cascade
1536_cascade
```

每种设置跑多个 seed，先建议：

```Plain Text
每张图 × 每种分辨率 × 3 个 seed
```

总量约为：

```Plain Text
20 × 4 × 3 = 240 个结果
```

---

**2\. 每个结果需要保存**

每个生成结果保存两类输出：

```Plain Text
1. 简化后 mesh / GLB
   大概百万面级别
2. 原始和简化后的都要做一个normal渲染出图，分辨率你自己试一下，高一些好，要看到细节
```

---

**3\. 网页可视化**

主要针对 **简化后的百万面 GLB** 做网页 viewer。

网页需求：

```Plain Text
一个页面对应一张 input image
横向比较不同 resolution
纵向比较不同 seed
所有 viewer 同步旋转、缩放、平移
可以切换不同 input image
```

基本布局：

```Plain Text
512     1024     1024_cascade     1536_cascade
seed 1      mesh    mesh        mesh              mesh
seed 2      mesh    mesh        mesh              mesh
seed 3      mesh    mesh        mesh              mesh
```
