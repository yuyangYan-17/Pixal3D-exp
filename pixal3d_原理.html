代码对应关系

1MoGe → FOV

上传脚本只读取 MoGe intrinsics 的 fx。

FOVx = 2 atan(W / (2 fx))
2ProjGrid 坐标

原始 grid 在 [-1,1]³，先做 Blender alignment，再除以 mesh_scale 和 2。

g=(x,y,z) R g = (x,-z,y) p = Rg / (2s)
3相机矩阵

front_view_transform_matrix 的 [1,3] 被替换为 -distance；投影函数再取逆矩阵。

T = [ R (0,-d,0) ] world_to_camera = inv(T)
4化简后的 camera coords

把步骤 2 和 3 合起来，旋转恰好抵消，得到非常直观的形式。

x_cam = x/(2s) y_cam = y/(2s) z_cam = z/(2s) - d depth = d - z/(2s)
5透视投影

这就是 project_points_to_image_batch 的核心。

f = W / (2 tan(FOV/2)) u = W/2 + f x_cam/depth v = W/2 - f y_cam/depth
6distance_from_fov

只用 target_point.x；传进去的 target_point.y 被计算成 y_ndc 后没有用于 distance。

reference raw grid = (-1,0,0) u_target = -extend d = f / [ s (W + 2 extend) ] extend=0,s=1: d = 1/[2 tan(FOV/2)]
